Tailscale CLI integration and network status control for Emacs.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=tailscale.el= provides an interactive interface to the Tailscale CLI directly
within Emacs. It allows you to inspect current tailnet status, copy node IPs,
send files via Taildrop, and control daemon connection state without leaving your editor.

** Features
- Interactive network status overview buffer (=tailscale-status=).
- Quick daemon control (=tailscale-connect=, =tailscale-disconnect=).
- Node IP completion and kill-ring copying (=tailscale-copy-ip=).
- Asynchronous Taildrop file dispatch (=tailscale-file-send=).

* Workflows
:PROPERTIES:
:CUSTOM_ID: workflows
:END:

** Inspecting Tailnet Status
Run =M-x tailscale-status= to open the =*Tailscale Status*= buffer showing your
current node, online status, IP addresses, and active peers.

Keybindings available in =tailscale-mode=:
| Key | Command                   | Description                   |
|-----+---------------------------+-------------------------------|
| =g= | =tailscale-status=        | Refresh status buffer         |
| =c= | =tailscale-connect=       | Connect daemon (~tailscale up~) |
| =d= | =tailscale-disconnect=    | Disconnect (~tailscale down~)   |
| =y= | =tailscale-copy-ip=       | Copy node IP to kill ring     |
| =f= | =tailscale-file-send=     | Send file via Taildrop        |

** Sending Files with Taildrop
Invoke =M-x tailscale-file-send= to choose a file and select an online peer.
The transfer proceeds asynchronously in the background.

* Commands & API
:PROPERTIES:
:CUSTOM_ID: commands
:END:

| Command                 | Summary                                                      |
|-------------------------+--------------------------------------------------------------|
| =tailscale-status=      | Display interactive network status buffer.                   |
| =tailscale-connect=     | Connect Tailscale daemon (~tailscale up~).                     |
| =tailscale-disconnect=  | Disconnect Tailscale daemon (~tailscale down~).               |
| =tailscale-copy-ip=     | Prompt for a node and copy its IP address to the kill ring.  |
| =tailscale-file-send=   | Send file to a peer node via Taildrop asynchronously.        |
