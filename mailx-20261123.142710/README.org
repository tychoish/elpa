* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

~mailx~ is an extensible, transport-independent mail management suite for GNU Emacs
and [[https://www.djcbsoftware.nl/code/mu/mu4e.html][mu4e]].  It provides declarative S-expression classification rules, a three-stage
cascading classifier, multi-tier attention bookmarks, reviewable bulk triage via
[[https://github.com/tychoish/hitl][hitl-plan]], context-aware Org mode links, and Model Context Protocol (MCP) inspection
tools.

** Key Features
:PROPERTIES:
:CUSTOM_ID: key-features
:END:

- *Declarative Rules DSL*: Express routing and attention policies with composable S-expressions (~:and~, ~:or~, ~:not~, ~:from~, ~:to~, ~:list~, ~:subject~, ~:has-unsubscribe~).
- *Delivery Exporters & Importers*: Export portable rule sets to [[https://github.com/nicm/fdm][fdm]] configuration or [[https://en.wikipedia.org/wiki/Procmail][procmail]] recipes, and import legacy procmail filter directories.
- *Three-Stage Classification Cascade*: Deterministic rule matching and correspondent caching in stage 1, receipt and transactional heuristics in stage 2, and optional LLM classification in stage 3.
- *Attention-Oriented Views*: Five attention tiers (~reply~, ~read~, ~cursory~, ~bulk~, ~junk~) with dynamic unread count annotations and custom headers columns.
- *Reviewable Bulk Triage*: Stage and execute batch mail operations (~mark-read~, ~refile~, ~tag~, ~unsubscribe~, ~block-sender~, ~expire-older~) using Human-in-the-Loop plans.
- *Context-Aware Org Integration*: Context-qualified ~mailx:~ link types that switch database contexts automatically before jumping to messages.
- *MCP Service*: Headless inspection tools (~list_unclassified~, ~test_rule~, ~add_rule~, ~stage_triage_plan~) guarded by path allowlists.

* Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:

Initialize ~mailx~ in your Emacs configuration with `mailx-global-mode`:

#+begin_src emacs-lisp
(use-package mailx
  :commands (mailx-global-mode mailx-setup mailx-make-context)
  :init
  (mailx-global-mode 1)
  :config
  (setq mailx-default-maildir "~/mail"
        mailx-archive-folder "/archive")

  ;; Optional: customize managed settings applied when mode is active
  ;; (setq mailx-global-managed-settings '(...))

  ;; Optional: configure account contexts
  (setq mu4e-contexts
        (list
         (mailx-make-context
          :name "personal"
          :full-name "Your Name"
          :address "you@example.com"
          :maildir "~/mail"
          :command "mbsync personal"))))
#+end_src

** Interactive Refile Rule Generation
:PROPERTIES:
:CUSTOM_ID: workflow-refile-rules
:END:

While viewing or navigating headers in mu4e, invoke ~M-x mailx-generate-refile-rule~.  You will be prompted to select a message field, specify a regular expression, choose a destination folder, and assign an attention tier.  Before saving, a live preview matches against the active database and reports matching counts.

** Attention Tier Navigation
:PROPERTIES:
:CUSTOM_ID: workflow-attention-tiers
:END:

Invoke ~M-x mailx-jump-to-tier~ to choose from the five tiers.  Each option displays real-time unread counts:
- *reply*: High-attention messages requiring personal responses.
- *read*: Substantive threads to read with lower immediacy.
- *cursory*: Informational messages, newsletters, notifications.
- *bulk*: High-volume automated communications.
- *junk*: Unsolicited messages and spam.

** Bulk Triage Plans
:PROPERTIES:
:CUSTOM_ID: workflow-bulk-triage
:END:

From a headers buffer, run ~M-x mailx-bulk-stage-current-view~ to snapshot the visible messages into a reviewable plan.  Inside the review interface, queue actions (~r~ for mark read, ~m~ for refile, ~b~ to block sender and trash) before committing them atomically.

* API Reference
:PROPERTIES:
:CUSTOM_ID: api-reference
:END:

| Function / Variable | Description |
|---|---|
| ~mailx-global-mode~ | Global minor mode managing mail hooks, advice, and settings lifecycle. |
| ~mailx-global-managed-settings~ | Alist of user settings applied when ~mailx-global-mode~ is enabled. |
| ~mailx-setup~ | Convenience command to enable ~mailx-global-mode~. |
| ~mailx-make-context~ | Constructor for isolated mu4e account contexts. |
| ~mailx-generate-refile-rule~ | Interactive rule creator with live query preview. |
| ~mailx-jump-to-tier~ | Annotated prompt to jump to attention tiers with unread counts. |
| ~mailx-bulk-stage-current-view~ | Stage visible messages into a Human-in-the-Loop triage plan. |
| ~mailx-capture-task~ | Capture an Org task and automatically refile upon completion. |
| ~mailx-sync-and-classify-async~ | Background process runner for mail fetch and classification. |
| ~mailx-mcp-register~ | Register MCP service and inspection tools. |
