* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=magit-dash= is a tabulated-list dashboard for tracking and managing multiple
local git repositories from a single buffer.  Includes integration with GitHub
(via [[https://github.com/jonathanchu/magit-gh][magit-gh]]) and relies heavily on [[https://magit.vc/][magit]].  Register repositories with
=magit-dash-register= (typically in your init file).  Open the dashboard with
=magit-dash-open=.

** ELPAish (Recommended)
:PROPERTIES:
:CUSTOM_ID: elpaish-recommended
:END:
Add the ELPAish repository to ~package-archives~:

#+BEGIN_SRC emacs-lisp
(add-to-list 'package-archives
             '("elpaish" . "https://tychoish.github.io/elpaish/snapshot/") t)
(package-refresh-contents)
#+END_SRC

You can install with =package-install=:

#+BEGIN_SRC emacs-lisp
(package-install 'magit-dash)
#+END_SRC

To verify package signatures, import the ELPAish signing key into
=package.el='s keyring and enable signature checking:

#+BEGIN_SRC emacs-lisp
(url-copy-file "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
               "elpaish-keyring.gpg" t)
(package-import-keyring "elpaish-keyring.gpg")
(setq package-check-signature t)
#+END_SRC

** Full Example Configuration

Below is an example ~use-package~ configuration block setting useful options with explicit defaults and keybindings:

#+BEGIN_SRC emacs-lisp
(use-package magit-dash
  :ensure t
  :after magit
  :defer t
  :commands (magit-dash-open
             magit-dash-open-other-window
             magit-dash-open-repo
             magit-dash-sync-repo
             magit-dash-gh-pr-dashboard-open
             magit-dash-gh-actions-fetch
             magit-dash-gh-prune-merged-branches
             magit-dash-gh-auth-switch)
  :bind (("C-c g d" . magit-dash-open)
         ("C-c g r" . magit-dash-open-repo)
         ("C-c g p" . magit-dash-gh-pr-dashboard-open)
         ("C-c g a" . magit-dash-gh-actions-fetch))
  :init
  ;; Install GitHub CI/PR status headers and dispatcher into magit-status
  (with-eval-after-load 'magit
    (require 'magit-dash-status)
    (magit-dash-status-setup))
  :config
  ;; Load optional features
  (require 'magit-dash-open)
  (require 'magit-dash-gh)
  (require 'magit-dash-gh-pr)
  (require 'magit-dash-gh-ci)
  (require 'magit-dash-gh-actions)
  (require 'magit-dash-worktree)
  (require 'magit-dash-submodules)
  (require 'magit-dash-timer)

  ;; Dashboard layout and column visibility
  ;; Available columns: name, branch, fetched, status, upstream, remote, ops
  (setq magit-dash-columns '((name     . t)
                             (branch   . t)
                             (fetched  . t)
                             (status   . t)
                             (upstream . t)
                             (remote   . t)
                             (ops      . t)))
  (setq magit-dash-show-discovered-worktrees t)        ; default: t (display worktrees)
  (setq magit-dash-show-discovered-submodules t)       ; default: t (display submodules)
  (setq magit-dash-render-branch-name-as-basename nil) ; default: nil (show full branch path)

  ;; Execution behavior
  (setq magit-dash-run-command-in-background nil)      ; default: nil (synchronous execution)

  ;; Magit-status integration (magit-dash-status)
  (setq magit-dash-status-enable t)                    ; default: t (insert headers in magit-status)
  (setq magit-dash-status-authored-prs-limit 15)       ; default: 15 (max authored PRs displayed)
  (setq magit-dash-status-cache-ttl 60)                ; default: 60 (seconds before cache invalidation)

  ;; GitHub integration limits (magit-dash-gh, magit-dash-gh-pr, magit-dash-gh-actions)
  (setq magit-dash-gh-pr-thread-limit 100)             ; default: 100 (max review threads fetched)
  (setq magit-dash-gh-prune-pr-limit 100)              ; default: 100 (max PRs checked for branch pruning)
  (setq magit-dash-gh-actions-run-limit 10)            ; default: 10 (recent runs listed for download)
  (setq magit-dash-gh-actions-include-failed-log t)    ; default: t (save separate failed-step log)
  (setq magit-dash-gh-collect-index-format 'json)      ; default: 'json (artifact index format)

  ;; Worktree management (magit-dash-worktree)
  (setq magit-dash-worktree-auto-symlink t)            ; default: t (auto-link shared paths on add)
  (setq magit-dash-worktree-global-symlinks
        '("node_modules" ".venv" ".env"))              ; default: '("node_modules" ".venv" ".env")

  ;; Repository switching (magit-dash-open)
  (setq magit-dash-open-scan-depth 2)                  ; default: 2 (directory scanning depth)

  ;; Refresh fetch & sync behavior
  (setq magit-dash-refresh-fetch t)                    ; default: t (fetch on refresh for configured repos)
  (setq magit-dash-refresh-fetch-min-interval 600)     ; default: 600 (10 minutes between refresh fetches)
  (setq magit-dash-refresh-sync-min-interval 3600)     ; default: 3600 (1 hour between refresh full syncs)

  ;; Periodic synchronization (magit-dash-timer)
  (setq magit-dash-sync-min-interval 300)              ; default: 300 (minimum seconds between auto-syncs)

  ;; Global sync hooks across all registered repositories
  ;; Ordering wraps outermost-to-innermost (pre runs before repo; post runs after repo)
  (magit-dash-set-global-hooks
   '(:sync (:post (message "magit-dash: sync complete")))))
#+END_SRC

** Key Options & Customization
:PROPERTIES:
:CUSTOM_ID: key-options--customization
:END:
- *Columns Visibility*: ~magit-dash-columns~ controls which columns are rendered in the dashboard table (=name=, =branch=, =fetched=, =status=, =upstream=, =remote=, =ops=).
- *Worktrees & Submodules*: ~magit-dash-show-discovered-worktrees~ and ~magit-dash-show-discovered-submodules~ toggle automatic inline listing of worktrees and submodules.
- *Async Execution*: ~magit-dash-run-command-in-background~ runs external repository commands asynchronously in a background compilation buffer when non-nil.
- *Status Buffer Integration*: ~magit-dash-status-enable~ inserts GitHub CI headers, PR status, and authored PR sections directly into ~magit-status~ buffers.
- *Cache TTL*: ~magit-dash-status-cache-ttl~ defines the freshness interval (in seconds) for cached GitHub CLI results.
- *Worktree Symlinks*: ~magit-dash-worktree-global-symlinks~ and ~magit-dash-worktree-auto-symlink~ automatically link shared environment directories (=node_modules=, =.venv=, =.env=) into newly created worktrees.
- *CI Log Capture*: ~magit-dash-gh-actions-include-failed-log~ creates filtered failure summaries alongside complete GitHub Actions run logs.
- *Refresh Fetch & Sync*: ~magit-dash-refresh-fetch~ (default ~t~), ~magit-dash-refresh-fetch-min-interval~ (default 600s / 10m), and ~magit-dash-refresh-sync-min-interval~ (default 3600s / 1h) control background fetches and repo-level ~:sync-on-refresh~ full syncs when refreshing the dashboard.

* Auto-Sync and Hooks
:PROPERTIES:
:CUSTOM_ID: auto-sync-and-hooks
:END:

Each auto-sync operation (=fetch=, =pull=, =commit=, =push=, and the =sync=
meta-operation that runs them together) can take a =:pre= hook, a =:post=
hook, and an =:operation= override, all under one =:hooks= keyword passed
to =magit-dash-register=:

#+BEGIN_SRC emacs-lisp
(magit-dash-register
 :name "myrepo" :path "~/src/myrepo"
 :auto-fetch t :auto-commit t
 :hooks '(:fetch  (:post (docs))               ;; docs = a :commands label
          :commit (:pre  (lint-staged))
          :sync   (:operation orchestrate      ;; full pipeline replacement
                   :post      (recompile-vendored))))
#+END_SRC

- =:pre= — targets run before the operation; a target signaling an error
  skips the operation (reported as =skipped=).

- =:post= — targets run after the operation succeeds (=ok= or a no-op
  =skipped=); failures here are logged but never fail the overall sync.

- =:operation= — replaces the default implementation for that operation.
  For =fetch=/=pull=/=commit=/=push= the step still only runs when its own
  =:auto-fetch=/=:auto-pull=/=:auto-commit=/=:auto-push= flag is set;
  for =sync= it replaces the *entire* default pipeline outright.

A target is a symbol (looked up as a label in =:commands=), a string (run
as a shell command in the repo directory), or a function of
=(REPO ON-COMPLETE)= where =ON-COMPLETE= accepts =ok=, =skipped=, or =error=.

=magit-dash-global-hooks= applies =:pre=/=:post= hooks (no =:operation=)
across every registered repo, using the identical shape. Ordering wraps
outermost-to-innermost: for =:pre=, global hooks run before repo hooks; for
=:post=, repo hooks run before global hooks (global closes last). Set it
with =magit-dash-set-global-hooks= rather than =setq=, to validate the hook

#+BEGIN_SRC emacs-lisp
(magit-dash-set-global-hooks '(:sync (:post (notify-dashboard))))
#+END_SRC

** Declarative Remote Host Sync
:PROPERTIES:
:CUSTOM_ID: declarative-remote-host-sync
:END:

For repositories synced across multiple workstations or remote hosts over SSH, =:remote-sync= declares mirror hosts, target branch, optional remote path, and merge strategy.

Options for =:remote-sync=:
- =:hosts= — list of remote hostnames/SSH targets (strings or symbols).
- =:branch= — target branch to rebase or merge against (defaults to current branch HEAD).
- =:path= — remote destination path (defaults to same absolute path as local).
- =:merge-method= — sync integration strategy: ='rebase= (default) or ='merge=.

=magit-dash= automatically generates per-host =sync-HOST= commands (e.g. =sync-deleuze=, =sync-spinoza=) in the repository command picker:

#+BEGIN_SRC emacs-lisp
(magit-dash-register
 :name "blog"
 :path "~/src/blog"
 :repo "git@github.com:tychoish/blog.git"
 :remote-sync '(:hosts ("deleuze" "spinoza")
                :branch "master"
                :merge-method merge)
 :commands '((push  . "make push")
             (build . "make build"))
 :sort-hint 20)
#+END_SRC

Each generated =sync-HOST= command executes a robust multi-stage sync pipeline:
1. *Remote SSH*: Stage, fetch, and rebase (or merge when =:merge-method= is ='merge=) on the target branch on the remote host, then commit and push.
2. *Local*: Stage, fetch, rebase/merge, clean deleted files, commit, and push from the local repository.
3. *Remote SSH*: Repeat remote stage/rebase/commit/push to incorporate local changes.
4. *Local*: Final fetch and rebase/merge.

To run remote sync automatically during repo sync, you can wire a generated target to =:hooks=:

#+BEGIN_SRC emacs-lisp
(magit-dash-register
 :name "mail"
 :path "~/mail"
 :repo "git@github.com:tychoish/mail.git"
 :remote-sync '(:hosts ("deleuze" "spinoza")
                :branch "master")
 :hooks '(:sync (:pre (magit-dash-save-project-buffers)
                 :operation sync-deleuze)))
#+END_SRC

** Full Auto-Sync with Bootstrapping and CI
:PROPERTIES:
:CUSTOM_ID: full-auto-sync-with-bootstrapping-and-ci
:END:

(magit-dash-register
 :name "myproject"
 :path "~/src/myproject"
 :repo "git@github.com:tychoish/myproject.git"
 :auto-fetch t
 :auto-pull t
 :auto-commit t
 :auto-push t
 :sync-branches '("main" "master")
 :include-prs t
 :include-ci t
 :sort-hint 10)

* Related Packages
:PROPERTIES:
:CUSTOM_ID: related-packages
:END:

- [[https://magit.vc/][magit]]: The foundational Git porcelain for Emacs upon which =magit-dash= builds. Provides repository status buffers, diffing, staging, committing, and transient command dispatchers.
- [[https://github.com/jonathanchu/magit-gh][magit-gh]]: GitHub CLI integration for Magit, providing dedicated pull request, issue, and review workflows inside Emacs.
- [[https://cli.github.com/][gh]] (GitHub CLI): The official GitHub command-line interface, used under the hood by =magit-dash= to authenticate, inspect PR review threads, download CI logs, and query status.
- [[https://tychoish.github.io/elpaish/][elpaish]]: Emacs Lisp package management, recipe build system, and snapshot ELPA archive used to distribute =magit-dash=.
- [[https://github.com/alphapapa/magit-todos][magit-todos]]: Integrates TODO items directly into Magit status buffers.
- [[https://github.com/magit/forge][forge]]: An alternative Git forge client for Magit supporting GitHub, GitLab, and Gitea.
