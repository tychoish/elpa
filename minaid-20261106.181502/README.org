Unified minad completion and selection stack for Emacs.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=minaid= provides consolidated configuration and unified lifecycle management for the modern "minad" completion ecosystem:

- *Vertico*: Minimal, vertical minibuffer completion UI with multiform view switching.
- *Marginalia*: Rich, aligned annotations for minibuffer candidates.
- *Orderless*: Component-based completion style with regex and literal matching.
- *Corfu*: Fast in-buffer popup completion overlay with history, quick jump, and indexing.
- *Cape*: Completion-at-point extensions and composable wrappers (Dabbrev, file, elisp, keywords).
- *Tempel*: Lightweight template expansion integrated into completion-at-point.
- *Consult*: Practical search and navigation commands (lazily integrated).
- *Embark*: Contextual minibuffer and in-buffer actions (on-demand).

** Architectural Principles
1. *Unified Lifecycle*: =minaid-mode= coordinates activation, buffer hooks, and teardown across all component packages in a single toggle.
2. *Fast & Lightweight Startup*: Direct interactive completion dependencies (=vertico=, =marginalia=, =orderless=, =corfu=, =cape=, =tempel=) are explicitly required up-front (~25ms), while heavyweight actions (=embark=) and search tools (=consult=) remain lazily loaded.
3. *Symmetric Teardown*: Disabling =minaid-mode= cleanly restores original completion styles, hooks, advice, and Xref display handlers.

* Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:

** ELPAish Package Archive
=minaid= is published on [[https://github.com/tychoish/elpaish][ELPAish]], a self-hosted Emacs Lisp package archive.
Add the ELPAish snapshot archive to your ~package-archives~:

#+begin_src emacs-lisp
(add-to-list 'package-archives
             '("elpaish" . "https://tychoish.github.io/elpaish/snapshot/") t)
(package-refresh-contents)
#+end_src

Once added, install via ~package-install~:

#+begin_src emacs-lisp
(package-install 'minaid)
#+end_src

Or using ~use-package~ with ~:ensure t~:

#+begin_src emacs-lisp
(use-package minaid
  :ensure t
  :config
  (minaid-mode 1))
#+end_src

** use-package with VC
On Emacs 30+ (or Emacs 29 with =package-vc=), you can install and track =minaid= directly from Git using ~:vc~:

#+begin_src emacs-lisp
(use-package minaid
  :vc (:url "https://github.com/tychoish/minaid")
  :config
  (minaid-mode 1))
#+end_src

** Manual Installation
Clone this repository locally:

#+begin_src bash
git clone https://github.com/tychoish/minaid.git ~/.emacs.d/site-lisp/minaid
#+end_src

Add it to your ~load-path~ and require the feature:

#+begin_src emacs-lisp
(add-to-list 'load-path "~/.emacs.d/site-lisp/minaid")
(require 'minaid)
(minaid-mode 1)
#+end_src

* Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:

A complete ~use-package~ configuration block showing keymap bindings and custom options:

#+begin_src emacs-lisp
(use-package minaid
  :ensure t
  :custom
  (minaid-vertico-count 25)
  (minaid-corfu-auto-delay 0.15)
  (minaid-corfu-text-auto-prefix 2)
  (minaid-corfu-prog-auto-prefix 3)
  :bind-keymap
  ;; Prefix keymap bindings with autoload trampolines
  (("C-c m" . minaid-global-map)
   ("C-c c" . minaid-consult-map)
   ("C-c TAB" . minaid-completion-map))
  :config
  ;; Activate the unified completion suite
  (minaid-mode 1))
#+end_src

** Keymaps & Entry Points
- =minaid-completion-map= (aliased to =minaid-map=): In-buffer completion actions (Tempel, Dabbrev, Cape backends, and in-region Corfu/Consult).
- =minaid-consult-map=: Practical search and navigation prefix map.
- =minaid-consult-search-map=: Line search and filtering submap mounted at =s=.
- =minaid-global-map=: Global bindings for Consult buffer switcher, find-at-point, and Embark actions.
