Two-way synchronization between Denote notes and remote services (Notion, Google Docs) in Emacs.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=denote-sync.el= provides interactive push and pull synchronization between local
[[https://github.com/protesilaos/denote][Denote]] notes and remote services via modular backends:

- *Notion* (=denote-sync-notion.el=) via the =npx ntn= CLI wrapper.
- *Google Docs* (=denote-sync-gdocs.el=) via the =gog= CLI wrapper.
- *Silo* (=denote-sync-silo.el=) copies and syncs notes into another Denote
  directory, optionally converting file type (Org, Markdown, text) and remapping
  =denote-sequence= signatures.  =denote-sync-silo-add-rule= defines a tree rule and
  =denote-sync-silo-export-tree= exports it, rewriting links between exported
  notes.  Markdown to Org conversion uses =mdwn.el=, which needs the =markdown=
  and =markdown-inline= tree-sitter grammars (set =mdwn-install-grammars= to
  install them on demand).  The target directory must not overlap the source.

** Features
- Push current Denote note to remote (=denote-sync-push=), creating or updating remote documents.
- Pull remote documents into Denote (=denote-sync-pull=), refreshing tracked files or creating new notes with metadata preserved.
- Content-hash change detection (=unchanged=, =local-only=, =remote-only=, =both-changed=).
- Three-way interactive conflict resolution via Ediff (=denote-sync-resolve-conflict=) with cached merge ancestors.
- Bounded async batch sync across all tracked notes (=denote-sync-all=).
- Integration with =denote-dash= saved views for tracked, conflicted, and remote-updated notes.
- Automatic YAML front matter tracking (=sync-<backend>-id=, =sync-<backend>-created=, =sync-<backend>-edited=, =sync-<backend>-sync-hash=). Conflicts are not stored: a note is conflicted when both its local body and the remote changed since the stored hash. Notes using the older =<backend>_id= spelling are still read and are renamed the next time they sync.
- Configurable parent registry (=denote-sync-parent-registry=) with ACR selection.

* Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:

** Prerequisites
- For Notion sync: Node.js and =ntn= (=npx ntn=).
- For Google Docs sync: =gog= CLI (=go install github.com/openclaw/gogcli/cmd/gog@latest=). See [[file:docs/google-docs-setup.org][docs/google-docs-setup.org]] for complete GCP credentials, file keyring, and multi-account setup.

** Manual Installation
#+begin_src bash
git clone https://github.com/tychoish/denote-sync.git ~/src/denote-sync
#+end_src

#+begin_src emacs-lisp
(add-to-list 'load-path "~/src/denote-sync")
(require 'denote-sync)
(require 'denote-sync-notion) ; optional
(require 'denote-sync-gdocs)  ; optional
(require 'denote-sync-silo)   ; optional
#+end_src

* Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:

Basic =use-package= configuration:

#+begin_src emacs-lisp
(use-package denote-sync
  :ensure t
  :defer t
  :commands (denote-sync-push denote-sync-pull denote-sync-resolve-conflict denote-sync-all))

(use-package denote-sync-notion
  :ensure t
  :after denote-sync)

(use-package denote-sync-gdocs
  :ensure t
  :after denote-sync)

(use-package mdwn
  :custom
  ;; install the markdown tree-sitter grammars on first use
  (mdwn-install-grammars t))

(use-package denote-sync-silo
  :after denote-sync
  :custom
  ;; set to t to allow a target directory that overlaps the source
  (denote-sync-silo-allow-overlap nil)
  :config
  (denote-sync-silo-add-rule
   :name "Public Documentation"
   :source-prefix "1=2"
   :target-directory "~/Documents/public-wiki/"
   :target-prefix "5"
   :target-format 'markdown-yaml
   ;; optional: retag on the destination side (also :tags, a list or function)
   :add-tags '("public")
   :remove-tags '("draft")))
#+end_src

* Commands & API
:PROPERTIES:
:CUSTOM_ID: commands
:END:

| Command                         | Summary                                                           |
|---------------------------------+-------------------------------------------------------------------|
| =denote-sync-push=              | Create or update the remote document for the current note.       |
| =denote-sync-pull=              | Refresh current note or import a new note from a remote ID/URL.   |
| =denote-sync-resolve-conflict=  | Three-way Ediff merge session against cached sync ancestor.       |
| =denote-sync-all=               | Bounded async batch sync over all tracked notes across backends.  |
| =denote-sync-silo-add-rule=     | Define a tree rule: source prefix, target silo, prefix, format.  |
| =denote-sync-silo-export-tree=  | Export and sync a rule's whole tree, rewriting internal links.    |
| =denote-sync-gdocs-set-account= | Assign or change Google account email on current note.           |
| =denote-sync-gdocs-add-account= | Authorize an additional Google account via OAuth in Emacs.       |
| =denote-sync-gdocs-add-parent=  | Register named parent target with account and Drive folder ID.   |
