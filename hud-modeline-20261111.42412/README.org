#+title: hud-modeline: Modular and Lightweight Modeline Engine for Emacs
#+author: Tycho Garen

* Overview

=hud-modeline= is a lightweight, modular mode-line engine for Emacs. It replaces
heavyweight modelines with a clean, responsive layout built around functional
segments.

* Features

- Clean left and right segment blocks with automatic padding and alignment.
- First-class segment management API (=hud-modeline-add-segment=, =hud-modeline-override-segment=, =hud-modeline-toggle-segment=).
- Interactive segment toggle using =annotated-completing-read=.
- Optional nerd-icons support for buffer icons, modified state, and diagnostic indicators.
- Seamless delight integration for custom major-mode lighters.
- Customizable box styling presets (=none=, =raised=, =bordered=, =padded=).

* Installation

Install via [[https://github.com/tychoish/elpaish][ELPAish]]:

#+begin_src elisp
(use-package hud-modeline
  :ensure t
  :hook (after-init . hud-modeline-mode))
#+end_src

* Configuration

#+begin_src elisp
(use-package hud-modeline
  :ensure t
  :init
  (setq hud-modeline-icons t
        hud-modeline-show-buffer-size t)
  :config
  (hud-modeline-mode 1))
#+end_src

* Managed defaults

=hud-modeline-mode= applies the =(SYMBOL . VALUE)= alist in =hud-modeline-settings=
when enabled and restores the saved prior default values when disabled.
Customize =hud-modeline-settings= before enabling =hud-modeline-mode= to adjust
the managed defaults.

HUD's default frame title uses =hud-modeline-instance-identity-function= to
obtain an instance name.  Its default consults Sprite when available and falls
back to =emacs=; set it to another function or nil to choose the identity.
Set =hud-modeline-frame-title-format= to replace the whole title format.
