* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=clix= provides declarative macro facilities to register command-line switches, flags, and subcommands dispatched via Emacs' =command-line-functions=:
- Single unified macro: =register-clix-flag= (aliased as =clix-register-flag=).
- Automatic support for both =--flag value= and =--flag=value= syntax.
- Optional automatic argument consumption and global variable assignment.
- Hooks integration to execute actions on specific hooks (e.g. =after-init-hook=).
- Zero runtime dependencies outside standard Emacs core.

** Defining Flags
:PROPERTIES:
:CUSTOM_ID: defining-flags
:END:

Register an option that consumes an argument into a variable:

#+begin_src emacs-lisp
(register-clix-flag profile
  :flag "--profile"
  :doc "Set active user profile."
  :consume t)
;; Access via clix-arg-profile
#+end_src

** Defining Subcommands
:PROPERTIES:
:CUSTOM_ID: defining-subcommands
:END:

Register subcommands (flags without leading dashes) with exit on completion:

#+begin_src emacs-lisp
(register-clix-flag test
  :flag "test"
  :doc "Run ERT test suite and exit."
  :consume nil
  :hook after-init-hook
  :action (ert-run-tests-batch-and-exit)
  :final t)
#+end_src

** Help
:PROPERTIES:
:CUSTOM_ID: help
:END:

Running =emacs --clix-help= or =emacs help= prints all registered options and docstrings and exits cleanly.
