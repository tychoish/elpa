A command registry with Transient and completing-read frontends, plus
the key, macro and operation helpers that go with it.

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

One repository with independent libraries and opt-in plugins. Load only what you need;
loading a library never installs hooks, advice or modes (the one
exception, =cmdr-mode=, is a plain minor mode you turn on yourself).

| Library        | Provides                                                      | Requires                                |
|----------------+---------------------------------------------------------------+-----------------------------------------|
| =cmdr=         | Command registry, =cmdr-menu=, =cmdr-dispatch=                | =transient=, =annotated-completing-read= |
| =cmdr-keys=    | Root map =cmdr-mode-map=, prefix and key-binding helpers      | built-ins only                          |
| =cmdr-macros=  | Toggle, command-generator, hook and deferred-keymap macros    | built-ins only                          |
| =cmdr-ops=     | Autoloaded interactive operations (windows, buffers, text)    | =annotated-completing-read= (at call time) |
| =cmdr-mode=    | Global minor mode attaching =cmdr-mode-map=                   | =cmdr-keys=                             |
| =cmdr-defaults= | Optional general editing and navigation bindings            | =cmdr-keys=                             |
| =cmdr-ecosystem= | Optional common package bindings                           | =cmdr-keys=, =cmdr-macros=              |

None of them depends on =xtd-macro= (xtdlib), hud-mode or any personal
configuration.

* Optional default bindings

The defaults plugin supplies general editing, display, help, buffer and
navigation bindings.  Loading it installs nothing; opt in explicitly:

#+begin_src emacs-lisp
(require 'cmdr-defaults)
(cmdr-defaults-install)
(cmdr-mode 1)
#+end_src

Installation is idempotent and configures the cmdr map without enabling it.
For common package bindings, also load =cmdr-ecosystem= and call
=cmdr-ecosystem-install=.  The two plugins can be installed independently
or together.

* Registry
:PROPERTIES:
:CUSTOM_ID: registry
:END:

#+begin_src emacs-lisp
(require 'cmdr)

(cmdr-register-command
 :category 'files
 :command 'save-all-buffers
 :description "Save every modified buffer"
 :transient-key "s")

(cmdr-menu)      ; Transient menu, built on each invocation
(cmdr-dispatch)  ; annotated completing-read over the same entries
#+end_src

=cmdr-register-command= keywords:

- =:category= :: symbol grouping entries; defaults to the defining file's
  name, or =cmdr=. An entry is identified by (category . command), and
  registering it again replaces it in place.
- =:command= :: the command symbol (required).
- =:description= :: menu label and =cmdr-dispatch= annotation.
- =:transient-key= :: menu key string; without one the entry is
  completion-only.
- =:display-name= :: =cmdr-dispatch= candidate; defaults to the command name.
- =:row= :: menu row, 1 to 3 (default 1); all entries of a category share a row.
- =:if= :: visibility predicate; nil hides the entry from both frontends.
- =:ifapt= :: availability predicate; non-nil shows the entry but
  invoking it signals =user-error=.
- =:exclude-from-transient= :: keep the entry in =cmdr-dispatch= only.

Invalid or conflicting entries signal =user-error= and leave the table
unchanged. =cmdr-reset-command-table= clears the registry; loading the
library never does.

=cmdr-transient-insert-suffix-once= (prefix loc suffix) inserts a suffix
into another Transient prefix unless a suffix with that key is already
present, and does nothing if the prefix is not yet defined.

* Key helpers
:PROPERTIES:
:CUSTOM_ID: key-helpers
:END:

From =cmdr-keys=:

- =cmdr-keys-prefix= (map seq label) :: create or relabel a prefix keymap
  at a key sequence, creating intermediate prefixes. The label is stored
  in the binding as a native (LABEL . KEYMAP) pair, so Help and which-key
  show it.
- =cmdr-keys-set= (map seq command) :: bind a full key sequence, creating
  intermediate prefixes.

From =cmdr-macros=:

- =cmdr-bind-deferred-keymap= (map key package keymap-symbol name) :: bind
  KEY to a labeled stand-in that loads PACKAGE on first use and then
  replays the keys into the real keymap.

#+begin_src emacs-lisp
(require 'cmdr-keys)
(require 'cmdr-mode)
(cmdr-keys-prefix cmdr-mode-map "C-c w" "windows")
(cmdr-keys-set cmdr-mode-map "C-c w u" #'increase-window-up)
(cmdr-mode 1)
#+end_src

* Operations and macros
:PROPERTIES:
:CUSTOM_ID: operations-and-macros
:END:

These names are deliberately unprefixed. They were checked against
Emacs and common packages for collisions.

- =cmdr-ops= (all autoloaded): =increase-window-up=, =-down=, =-left=,
  =-right=; =pin-buffer-to-window-toggle=; =frame-opacity-increase=,
  =-decrease=, =-reset=; =move-text-up=, =move-text-down=;
  =turn-on-soft-wrap=, =turn-off-soft-wrap=, =toggle-word-wrap=;
  =unfill-region=, =uniquify-region-lines=, =uniquify-buffer-lines=;
  =set-tab-width=, =text-scale-reset=, =insert-current-date=,
  =jump-to-elisp-help=, =toggle-local-whitespace-cleanup=,
  =save-all-buffers=, =buffer-line-count=, =buffer-directory=,
  =buffers-matching-path=, =buffers-matching-mode=,
  =kill-eldoc-and-help-buffers=, =kill-buffers-in-directory=,
  =kill-buffers-matching-path=, =force-kill-buffers-matching-path=,
  =kill-buffers-matching-mode=, =kill-all-reference-and-source-buffers=,
  =kill-buffers-visiting-missing-files=, =kill-buffer-and-delete-file=,
  =clean-kill-ring-clean=.
- =cmdr-macros=: =add-lazy-init=, =add-one-shot-hook=,
  =create-toggle-functions=, =make-read-extended-command-for-prefix=,
  and the prefixed =cmdr-bind-deferred-keymap=.

The kill operations keep Emacs's own vetoes
(=kill-buffer-query-functions=) and the save prompts for modified buffers.
